4. 搭配 lambda（自定义函数）
nums = [1, 2, 3, 4]
result = map(lambda x: x**2, nums)
print(list(result))  # [1, 4, 9, 16]
👉
lambda x: x**2
就是一个匿名函数，作用是把每个元素平方。
5. 多个可迭代对象
map()
可以同时迭代多个列表（类似“并行处理”）：
a = [1, 2, 3]
b = [4, 5, 6]
result = map(lambda x, y: x + y, a, b)
print(list(result))  # [5, 7, 9]
6. 总结对比
map()
：
函数式编程
风格，更简洁。
列表推导式：写法更直观，常用于 Pythonic 风格。

print(list(map(int, nums)))       # 用 map
print([int(x) for x in nums])     # 用列表推导式
两种写法等价，OJ 里一般用
map()
